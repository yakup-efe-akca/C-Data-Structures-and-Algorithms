# C Data Structures and Algorithms

A collection of data structures and algorithms implemented in C as part of my learning journey.

## Topics

- **Linked Lists**
  - Singly Linked List
- **Stacks**
  - Array-Based Stack
  - Linked List Stack
  - Min Stack
- **Queues**
  - Array-Based Queue
  - Circular Queue
  - Linked List Queue
- **Recursion and Backtracking**
  - N-Queens
  - Tower of Hanoi
- **Trees**
  - General Tree (Child-Sibling Representation)
  - Binary Tree (Traversals, Height, Node and Leaf Counting)
  - Expression Tree (Postfix Expression Construction)
  - Binary Search Tree (Insertion, Search, Deletion, Min/Max, IPL, BST Validation)

Implementations are organized into folders by topic.

## Building and Running

A C compiler (GCC or Clang) is required. Each program can be compiled and run individually from the repository root.

For example, to run Tower of Hanoi:

```bash
cc Recursion/Hanoi.c -o Recursion/Hanoi
./Recursion/Hanoi
```

To run a Stack implementation:

```bash
cc Stack/Stack.c -o Stack/Stack
./Stack/Stack
```

To run a Binary Search Tree implementation:

```bash
cc Trees/BinarySearchTree.c -o Trees/BinarySearchTree
./Trees/BinarySearchTree
```
