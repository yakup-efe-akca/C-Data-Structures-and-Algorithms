# C Data Structures and Algorithms

A growing collection of data structures and algorithms implemented
in C as part of my learning journey.

## Topics

- Linked Lists
- Stacks
- Queues
- Recursion and Backtracking

Implementations are organized into folders by topic.

## Building and Running

A C compiler is required. Each program can be compiled and run
individually from the repository root.

For example:

```bash
cc Stack/Stack.c -o Stack/Stack
./Stack/Stack
```
