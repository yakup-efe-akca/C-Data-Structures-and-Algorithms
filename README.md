# C Data Structures and Algorithms

A growing collection of data structures and algorithms implemented in C as part of my learning journey.

## Topics

- Linked Lists
- Stacks
- Queues
- Recursion and Backtracking
  - N-Queens
  - Tower of Hanoi

Implementations are organized into folders by topic.

## Building and Running

A C compiler (GCC or Clang) is required. Each program can be compiled and run individually from the repository root.

For example, to run Tower of Hanoi:

```bash
cc Recursion/Hanoi.c -o Recursion/Hanoi
./Recursion/Hanoi
```

Or to run a Stack implementation:

```bash
cc Stack/Stack.c -o Stack/Stack
./Stack/Stack
```
